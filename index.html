📥 Como Instalar

🐧 Instalação no Linux

  1. Clone o repositório: git clone https://github.com/lpx-tecnologia/lpx-monitoramento.git cd lpx-monitoramento
  2. Execute o instalador automático: chmod +x setup.sh ./setup.sh
  3. Ou instale manualmente: python3 -m venv venv source venv/bin/activate pip install -r requirements.txt python app.py
  4. Acesse o sistema: http://localhost:5000 Usuário: admin Senha: admin123

🍎 Instalação no macOS

  1. Instale o Python (se necessário): brew install python3
  2. Clone o repositório: git clone https://github.com/lpx-tecnologia/lpx-monitoramento.git cd lpx-monitoramento
  3. Execute: chmod +x run.sh ./run.sh
  4. Acesse: http://localhost:5000 Login: admin / admin123

🪟 Instalação no Windows

  1. Instale o Python:

    Baixe em: python.org

    ⚠️ Marque "Add Python to PATH" na instalação!

  2. Clone o repositório: git clone https://github.com/lpx-tecnologia/lpx-monitoramento.git cd lpx-monitoramento
  3. Execute o arquivo run.bat:

    Clique duas vezes em run.bat

    Ou no terminal:

    run.bat
  4. Acesse: http://localhost:5000 Login: admin / admin123

🐳 Instalação com Docker

  1. Build da imagem: docker build -t lpx-monitoramento .
  2. Execute o container: docker run -p 5000:5000 lpx-monitoramento
  3. Acesse: http://localhost:5000
