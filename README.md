# 🔒 LPX - Sistema de Segurança e Monitoramento

![LPX Logo](https://img.shields.io/badge/LPX-Segurança-00ff00)
![Python](https://img.shields.io/badge/Python-3.8+-blue)
![License](https://img.shields.io/badge/License-MIT-green)

Sistema inteligente de vigilância com câmera virtual, reconhecimento de padrões e central de alertas.

## ✨ Funcionalidades

- 📹 Monitoramento em tempo real com câmera virtual
- 🚨 Central de alertas com filtros (dia/semana/mês/ano)
- 👥 Detecção e contagem de pessoas
- 🚗 Registro de veículos
- 👤 Simulação de reconhecimento facial
- 📊 Dashboard com estatísticas
- 🔐 Sistema de login seguro
- 📱 Interface responsiva
- 🌐 Compatível com múltiplas câmeras

## 🚀 Instalação Rápida

### Linux/Mac:
```bash
git clone https://github.com/seu-usuario/lpx-monitoramento.git
cd lpx-monitoramento
chmod +x setup.sh run.sh
./setup.sh
./run.sh
